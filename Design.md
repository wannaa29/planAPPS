# Design System
# WorkFlow Planner

## 1. Design Philosophy

WorkFlow Planner should feel like:

> A calm command center for your work.

The UI should reduce cognitive load.

The user should immediately understand:

1. What is happening now?
2. What needs attention?
3. What is coming next?
4. What is at risk?

---

# 2. Visual Style

Style:

- Minimal
- Modern
- Professional
- Clean
- Productivity-focused
- Information-dense but readable

Avoid:

- Excessive gradients
- Glassmorphism everywhere
- Excessive shadows
- Large decorative graphics
- Excessive animation

---

- Primary buttons

## Warning

`#D97706`

- Upcoming deadline
- At risk

## Danger

`#DC2626`

- Overdue

`#2563EB`

# 5. Typography

Use:

`Inter`

Hierarchy:

- Page title: 24–32px
- Section title: 18–20px
- Body: 14–16px
- Small metadata: 12–14px

Use font weight carefully.
